# Regulatory genomics: practicals

Jupyter notebooks for the practicals of the course regulatory genomics, published as a website with [Jupyter Book](https://jupyterbook.org) on GitHub Pages.

## Repository structure

```
myst.yml                  Jupyter Book configuration (table of contents, excluded files)
index.md                  landing page of the website
.github/workflows/        GitHub Action that builds and deploys the website
tools/nbtools.py          helpers to build and execute notebooks from Python scripts
topics/<topic>/           one folder per topic
    index.md              topic overview (paper, data, software)
    *.ipynb               the notebooks (with saved outputs)
    scripts/              scripts that build/execute the notebooks and run long steps
    data/                 working directory of the notebooks (not in git)
archive/                  old material, not published
```

## Building the website locally

```
mamba create -n jupyterbook -c conda-forge "jupyter-book>=2" nodejs
mamba activate jupyterbook
jupyter-book build --html     # result in _build/html
jupyter-book start            # or: preview with live reload
```

The notebooks are **not** executed when the website is built; the outputs saved in the notebooks are shown. Notebooks therefore have to be executed (locally, with the data) before they are committed.

## Notebooks are generated by scripts

The notebooks of a topic are written as Python scripts in `topics/<topic>/scripts/build_*.py`:

```
mamba create -n nbexec -c conda-forge nbconvert nbclient nbformat ipykernel
python topics/bulk-rna-seq/scripts/build_part1.py --execute        # build and execute
python topics/bulk-rna-seq/scripts/build_part1.py --markdown-only  # only update the text, keep outputs
python topics/bulk-rna-seq/scripts/build_part1.py                  # build without outputs
```

Cells tagged `skip-execution` (full download, genome index, alignment) are not executed by `--execute`; these steps are run separately with the scripts in `topics/<topic>/scripts/`.

## Adding a topic

1. Create `topics/<new-topic>/` with an `index.md` and the notebooks.
2. Add the topic to the `toc` in `myst.yml` and to the list in `index.md`.
3. Put large data in `topics/<new-topic>/data/` (ignored by git).
